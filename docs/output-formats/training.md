# Training file

!!! note
    Check the [`learn`](../commands/learn.md) command for the new
    interactive approach.

Plain-text drill file for typing-practice tools like
[Monkeytype](https://monkeytype.com/) custom mode. Copy a line of 10
words at a time into the tool to help learn the chords:

```text
the and you have that for with this not but
t   a   y   h    th   f   w    ti   n   b
```
