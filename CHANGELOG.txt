v2.2.0

- Book mode: the current word is now highlighted yellow when it's a
  learned chord (previously only upcoming words were highlighted).
- Learn mode: overdue detection now uses calendar date instead of
  wall-clock time, matching Anki's behavior — cards due later today
  are no longer skipped.
- Learn mode: lapsed (Relearning) cards no longer show the chord by
  default — it only reappears on a current-word error, same as
  mastered words.
